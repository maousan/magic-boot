# 东信和平插件桌面端管理后台

## Pitch

东信和平（DXHP）插件的仓库管理操作目前仅通过 PDA 手持终端页面完成，每次只能操作单条记录。仓库管理员在桌面端需要一个表格化的 CRUD 管理界面来提升批量操作效率。

## 用户故事

**作为**仓库管理员（桌面端），
**我希望**通过一个桌面浏览器访问管理后台，
**以便**高效地管理 LED 设备绑定、标签绑定、库位导入和批次 EPC，而不是逐条通过 PDA 操作。

### 核心场景

1. 管理员打开管理后台，输入配置的账号密码登录
2. 查看 LED 设备列表，对设备执行开灯/关灯控制
3. 管理库位与 LED 设备的绑定关系（创建/删除）
4. 管理库位与电子标签的绑定关系（创建/解绑）
5. 通过 Excel 批量导入库位信息
6. 管理批次 EPC 绑定记录（查询/绑定/解绑）

## 边界

### 在范围内

- 独立 Vue3 + Vite + Naive UI 前端项目
- 前端配置认证（.env 文件设置账号密码）
- LED 设备管理、LED 绑定管理、标签绑定管理、库位导入、批次 EPC 管理
- 构建产物部署到插件 static/admin/ 目录

### 不在范围内

- PDA 手持终端页面（保留不动）
- Sa-Token 认证集成
- 移动端适配
- 亮灯链路模拟器
- RFID 控制
