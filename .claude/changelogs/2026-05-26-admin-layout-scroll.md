# 管理后台整体布局滚动调整

## 背景

管理后台需要明确为左侧菜单栏、右侧页面内容栏的布局结构，并让页面内容高度自适应容器，超出内容时只在右侧内容栏显示滚动条。

## 变更

- 全局 `html/body/#app` 设置为满高，禁止 `body` 级滚动。
- `AdminLayout` 调整为左侧菜单、右侧主区域的满高布局。
- 右侧主区域固定顶部栏高度，内容区域独立滚动。
- 库存查询页面改为占满内容容器高度，筛选区和分页固定，表格主体在剩余高度内滚动。
- 仪表盘、数据库管理、Magic-API 页面去除对 `100vh - 120px` 的硬编码依赖，改为跟随内容容器高度。

## 影响范围

- 仅影响 `dongxinheping-admin` 后台整体布局与滚动行为。
- 业务接口和页面数据逻辑未调整。
