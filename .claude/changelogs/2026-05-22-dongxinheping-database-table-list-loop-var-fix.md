# 东信和平数据库表列表循环变量修复

## 背景

“获取表列表”接口执行时报错：变量名不能定义为关键字。magic-script 当前语法不支持在 `for (...)` 初始化段中声明 `var`。

## 变更

- 将 JavaScript 风格的 `for (var ...; ...; ...)` 改为项目内已有的 `for (table in tables)` 集合遍历写法。
- 同步更新循环内字段赋值，直接给当前 `table` 补充 `columns`。

## 影响

- 不改变接口路径、SQL 查询和返回结构。
- 需要重新加载 magic-api 资源或等待编辑器保存刷新后生效。
