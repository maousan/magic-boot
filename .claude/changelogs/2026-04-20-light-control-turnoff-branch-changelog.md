# 变更日志：亮灯灭灯控制接口完善灭灯分支

## 变更日期
- 2026-04-20

## 变更类型
- fix

## 变更范围
- `data/dongxinheping/api/东信和平/亮灯控制/亮灯灭灯控制.ms`

## 变更内容
- 修复变量名拼写错误：`modelValue` -> `modeVal`，避免模式判断失效。
- 补充灭灯分支逻辑：
  - 当本波次无在线拣货用户时，按波次下全部库位异步触发灭灯。
  - 当仍有在线拣货用户时，按未完成库位重新补亮灯，颜色按单人/多人策略自动选择。
- 增加亮灯分支兜底：
  - 查询未完成库位并异步亮灯。
  - 多用户时优先使用 `mixColor`，未配置则回退 `CYAN`。
- 增加 `Forest` 导入，确保配置读取稳定。
- 增加关键日志，便于追踪异步亮灭灯派发行为。

## 兼容性说明
- 本次为逻辑补全与修复，不改变接口入参/出参结构。
- 仅影响 `/api/light/control` 内部执行策略。
