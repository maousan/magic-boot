# 亮灯链路模拟页面模块化改造计划

## 目标
- 将 `light-chain-simulator.html` 拆分为两个模块：`业务模拟` 与 `定时器模拟`。
- 优先实现业务模拟链路：波次列表 -> 明细 -> 自动上传 -> 修改字段 -> 完成。

## 业务模拟流程
1. 展示波次单列表（模拟数据）。
2. 点击某个波次单进入拣货明细视图。
3. 进入明细时自动调用 `POST /api/light/picking/upload`。
4. 用户可在表格中修改明细字段。
5. 点击“完成”调用 `POST /api/light/picking/complete`。

## 定时器模拟（基础版）
- 提供间隔配置与启动/停止按钮。
- 周期性调用 `POST /api/light/control`。

## 验证点
- 模块切换正常。
- 点击波次会自动触发上传。
- 修改明细后点击完成会触发完成接口。
- 定时器可启动、触发、停止。
