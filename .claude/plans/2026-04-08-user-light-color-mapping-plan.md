# 2026-04-08 实施计划：用户ID-灯光颜色映射

## 目标
- 新增数据库表，维护 `user_id -> color` 映射。
- 亮灯流程按用户ID优先取映射颜色，实现“不同用户显示不同灯光”。
- 未配置映射时保持现有颜色兜底逻辑。

## 实施步骤
1. 新增 Flyway 迁移脚本
- 创建 `t_user_light_color` 表。
- 约束：`user_id` 唯一，`color` 非空。

2. 新增颜色解析函数
- 新增 `@/utils/getUserLightColor` 工具函数。
- 输入 `userId`，查询映射表并返回合法颜色（RED/GREEN/BLUE/YELLOW/CYAN），未命中返回 `null`。

3. 改造亮灯流程
- `拣货数据上传.ms`：亮灯前优先用映射颜色，未命中再按原逻辑（单人GREEN/多人BLUE）。
- `拣货完成.ms`：亮灯前优先用映射颜色，未命中再按原逻辑（单人GREEN/多人CYAN）。

4. 补充接口测试用例
- 在 `.http` 中新增“配置映射后按用户色亮灯”的场景说明与请求。

5. 验证与文档
- 执行编译验证。
- 输出变更日志、测试报告、里程碑文档。
