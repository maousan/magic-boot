# 东信和平库位-巷道灯绑定单页面实施计划（PDA兼容）

## 1. 目标
- 基于现有接口 `POST/DELETE /api/location/led-mapping` 实现独立前端单页面。
- 页面路径：`/pda/led-mapping.html`。
- 适配移动端并优先兼容工业 PDA 浏览器。

## 2. 实施内容
- 新增独立静态页（原生 JS ES5，无第三方依赖）：
  - 创建绑定：`lotNo + ledId`。
  - 删除绑定：`lotNo`。
- 统一请求封装：`XMLHttpRequest`。
- 响应展示：请求参数、HTTP 状态、接口 code/message/data、耗时、原始返回。
- PDA 操作优化：
  - 输入控件与按钮触控尺寸放大。
  - 默认焦点在创建 lotNo 输入框。
  - 回车即提交当前表单。
  - 请求过程中按钮禁用，防重复提交。

## 3. 兼容与约束
- 不新增后端接口，不改现有数据库逻辑。
- 不依赖 `fetch`、Promise、现代构建工具。
- 移动优先样式，避免复杂动画与高风险 CSS 特性。

## 4. 验收标准
- 页面可通过 `/pda/led-mapping.html` 访问。
- 创建与删除操作可完整调用现有接口。
- 必填校验在前端生效，缺参不发请求。
- 重复绑定等后端错误可被清晰展示。
- PDA 场景下支持扫码后回车直接提交。
