# 里程碑：文件列表增加 hasChild 字段

日期：2026-03-26  
范围：`data/magic-api/api/系统管理/文件管理/文件浏览/获取文件列表.ms`

## 变更内容（已完成）
- 在分页列表查询结果中新增 `hasChild` 字段（`0/1`）。
- `hasChild` 通过 `exists` 子查询判断当前节点是否存在未删除子节点（同 `storage_key` 维度）。
- 主查询增加表别名 `f`，并同步调整筛选与排序字段引用，避免歧义。

## 设计意图
- 支持前端目录树懒加载时快速判断是否展示展开箭头。
- 保持原分页、筛选与排序语义不变，降低联调影响面。

## 验收建议
- 在根目录与多级目录分别验证 `hasChild` 返回值准确性。
- 在多存储源场景验证 `hasChild` 不串源（仅统计同 `storage_key`）。
