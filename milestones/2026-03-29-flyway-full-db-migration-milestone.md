# 2026-03-29 Flyway 全库自动迁移机制里程碑

## 里程碑目标
建立统一、可追踪、可审计的数据库迁移机制，替代手工 SQL 执行流程。

## 完成项
1. Flyway 依赖接入并由主应用统一执行迁移。
2. 启动阶段自动迁移与失败阻断策略启用。
3. 基线与增量迁移脚本拆分完成（含插件治理字段升级）。
4. 迁移规范文档落地，明确迁移目录、命名和发布要求。

## 验收标准
- 空库可通过 Flyway 建库启动。
- 存量库可通过 baseline 平滑接入。
- 插件治理字段增量迁移可重复安全执行。

## 后续建议
1. 增加专门的迁移集成测试（空库/存量库双场景）。
2. 在 CI 平台固化迁移验证步骤并设置阻断门禁。
3. 逐步清理历史 `db/*.sql` 与运行流程之间的耦合。
